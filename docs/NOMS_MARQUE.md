# Noms de marque — candidats (triés par pertinence)

Objectif : trouver un nom **brandable** (distinctif, mémorable, prononçable FR + EN) pour la plateforme de collecte de données terrain, avec un domaine probablement disponible. Nom de travail actuel : *TerraCollect*.

> ⚠️ **Disponibilité des domaines non vérifiée en direct.** La colonne « Dispo estimée » suppose qu'un mot inventé est rarement déposé — **à confirmer chez un registrar** (Namecheap, Gandi, OVH…) avant tout choix. Vérifier aussi les marques (INPI/EUIPO/USPTO) et les réseaux sociaux (@handle). Éviter toute proximité avec les concurrents (Kobo, ODK, Fulcrum, Survey123, CommCare, Fathom, Meridian).

## Critères de scoring
- **Sens** : lien avec collecte / terrain / carte / fiabilité.
- **Marque** : court, distinctif, prononçable dans les deux langues, pas de mauvaise connotation.
- **Domaine** : probabilité que `.com`/`.app`/`.io` soit libre (favorise les mots inventés).

## Recommandation

- **Top 3 à vérifier en priorité :** **Kolektu**, **Cairnly**, **Terravue**.
  - *Kolektu* : le plus « global » et le plus sûr côté domaine.
  - *Cairnly* : la meilleure métaphore métier (le cairn = repère de terrain = point de données).
  - *Terravue* : le plus « joli » et parlant en français, si le `.com` est acceptable en `.app`.
- **Réflexes avant de trancher :**
  1. Vérifier `.com` **et** un plan B (`.app`, `.io`, `co`) chez un registrar.
  2. Recherche marque (EUIPO/INPI + USPTO) pour la classe logiciel (9/42).
  3. Handles réseaux (@nom) et absence de sens négatif dans les langues cibles (swahili, arabe, portugais, espagnol).
  4. Test « au téléphone » : épeler le nom à voix haute — si l'interlocuteur doit demander l'orthographe, c'est un signal faible.
